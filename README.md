# Fishy Shooter
Description - a top-down shooter with ability selection system, multiple enemy types with different behaviors, waves and levels, and a modular codebase.

Open index.html in a browser to run.

Made using vanilla JavaScript, HTML5 Canvas, Web Audio API, and ES Modules.

Made in one large script, then refactored into smaller pieces.

## Controls
W/Up Arrow - move forward

S/Down Arrow - move backward

A/Left Arrow - turn left

D/Right Arrow - turn right

Left Click - shoot

Middle Click / Space - movement skill

## Planned features
Upgrade screen between waves.

Unique graphics per ability combination.

Bosses.
